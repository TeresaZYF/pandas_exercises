# Python Training & Learning Design Portfolio

**Teresa Zhu — Digital Workshop Center (DWC)**

Selected examples of the design approach used for a hands-on Python, data analysis and introductory machine learning course. Designed for adult learners transitioning into technical work, with live exercises in Google Colab, study guides, and assessments. The summaries below are excerpts, not the full course materials.

## Course sequence

**Phase 1 — Data analytics with pandas:** inspecting and cleaning data; filtering, sorting, joining and aggregating; exploratory visualization; data-storytelling midterm.

**Phase 2 — Machine learning with scikit-learn:** regression by hand; regression and classification; model evaluation; decision trees and ensembles; cross-validation, tuning and principal component analysis; applied capstone.

## Selected teaching artifacts

### 1. Live Google Colab notebooks
Six representative classes move from first DataFrame to building and interpreting models.
- **Intro to pandas:** inspecting columns, types, indexing and sorting with small examples
- **Pandas deeper dive:** answering business questions using filtering and groupby
- **Retail analytics:** calculating revenue, monthly changes and charts from transaction data
- **Visual storytelling:** describing patterns before choosing the next visualization
- **Regression by hand:** estimating coefficients using sums before checking with scikit-learn

**Example prompt:** *You need average points by franchise and year. Filter, group, aggregate, then reshape. Explain what each step contributes.*

### 2. Reusable field guides
Thirteen concise algorithm guides use a common structure: when to use the method, key concepts, code, and what to watch for. A searchable command reference reinforces skills introduced during class.

### 3. Authentic assessments
- Midterm: students choose a public dataset, clean and visualize it, and write interpretations
- Capstone: end-to-end business problem, reproducible notebook, multiple modeling approaches and a recorded walkthrough
- Short practice assignments, reading checks, and simulation problems support formative assessment

## Instructional principles
- **Hints identify the tool without giving away the solution**
- **Outputs make self-checking possible**
- **Learners explain a chart before producing another**
- **Core algorithms begin with intuition or manual calculation**
- **Repeated notebook structure reduces extraneous cognitive load**
